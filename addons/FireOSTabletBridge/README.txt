This is a Godot Android Plugin v2 export addon.

The AARs are built by .github/workflows/build-android-bridge.yml and copied to:
  bin/debug/FireOSTabletBridge.aar
  bin/release/FireOSTabletBridge.aar

Do not export an Android build until both AAR files have been generated.
Enable this plugin in Project > Project Settings > Plugins and enable Gradle Build in the Android export preset.
